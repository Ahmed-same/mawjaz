# موجز (Mawjaz)

موقع لإدارة ملخصات الاجتماعات: يرفع المستخدم تسجيل أو ملاحظات الاجتماع، ويحصل على ملخص واضح بالقرارات والمهام والنقاط المهمة، مع لوحة تحكم تعرض عدد المستخدمين والاجتماعات والملخصات.

## المميزات

- **تلخيص الاجتماعات**: ملخصات منظمة بالقرارات والمهام.
- **أدوار وصلاحيات**: مستخدم، قائد فريق، ومدير — لكل دور صلاحياته ولوحته الخاصة.
- **تسجيل ودخول**: إنشاء حساب وتسجيل دخول (واجهة تجريبية بالكامل، البيانات في المتصفح).
- **إحصائيات**: عدد المستخدمين والاجتماعات والملخصات الجاهزة.
- **تصميم هادئ**: ألوان مريحة وواجهة عربية بالكامل (RTL).

## التقنيات

- HTML5 / CSS3 / JavaScript (بدون أي إطار عمل)
- خط Tajawal من Google Fonts

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## الصفحات

| الصفحة | الوصف |
|---|---|
| `index.html` | الصفحة الرئيسية والتعريف بالخدمة |
| `register.html` | إنشاء حساب مع اختيار الدور |
| `login.html` | تسجيل الدخول (+ حسابات تجريبية) |
| `dashboard.html` | لوحة التحكم حسب دور المستخدم |
